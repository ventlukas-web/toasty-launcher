POLDI CLIENT LAUNCHER
- Rotes Design, Name "Poldi Client", ohne Toasty Client.
- Hauptversion: Minecraft 26.2 mit Fabric + Fabric API + Poldi Client Mod.
- Alle anderen Release-Versionen (ab 1.18) spielbar mit Fabric + Fabric API, Mods per Modrinth.
- Poldi-Mod-Jar in poldi-launcher/mod/ legen (siehe mod/README.txt).
- Build: Actions -> "Build Poldi Client Launcher" -> Release "poldi-launcher-latest" -> PoldiClient-windows.zip.
- Daten liegen in %APPDATA%\PoldiLauncher (getrennt vom Toasty Launcher).
